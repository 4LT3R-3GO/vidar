# Install

<b> Required version: 3.50.3 </b>

##  How to install on Windows

* Extract all files
* Add to C\sqlite (or create, if not existing)
* win+r -> sysdm.cpl --> Advanced - Environment Variables
* Under Environment, find and edit <b>Path</b>
* Add `C:\sqlite\`
* Check if it has been installed in CMD: `sqlite3 --version`

* add sqlite to vscode path: $env:Path += ";C:\SQLite"
